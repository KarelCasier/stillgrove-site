# Stillgrove brand

Two birch trunks inside a ring: a grove, and the pause sign. The same two trunks are the double l in "still".

## Files

| File | Use |
| --- | --- |
| `stillgrove-symbol-on-dark.svg` / `-on-light.svg` | Symbol alone: avatars, stamps, app icons |
| `stillgrove-horizontal-on-dark.svg` / `-on-light.svg` | Headers, email signatures, store pages |
| `stillgrove-stacked-on-dark.svg` / `-on-light.svg` | Splash screens, posters, credits |
| `stillgrove-wordmark-on-dark.svg` / `-on-light.svg` | The name alone, when the symbol is already nearby |
| `../favicon.svg`, `../apple-touch-icon.png` | Browser tab and home-screen icons (simplified bark for small sizes) |

All files have transparent backgrounds. "On dark" artwork is bone; "on light" artwork is forest ink.

## Colour

| Name | Hex | Role |
| --- | --- | --- |
| Forest | `#131a15` | Background |
| Bone | `#e7e3d6` | Symbol and name on dark |
| Forest ink | `#1f2a22` | Symbol and name on light |
| Lichen | `#77876f` | Middle band of the reveal; quiet UI text |

## Type

The wordmark is Newsreader (SIL Open Font License) set at 72 pt optical size, weight 500, converted to outlines, with the two l's redrawn as birch trunks. Don't retype it; use the files.

## Motion

The splash on the site plays in three beats over 2.9 s: light rises through the trunks while the ring draws itself, the name fades up, a gust sways the trunks, and everything settles still. It is skipped for people who prefer reduced motion.
